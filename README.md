 System & Git Health Check (`system-health-monitor`)

A lightweight Python Command-Line Interface (CLI) utility that verifies local system metrics, environment readiness, and Git configuration in a single command.

Features

- System Metrics:** Checks available disk space and basic system environment details.
- Python Environment Verification:** Displays the active Python runtime version.
- Git Identity & Config Check:** Verifies local Git user configuration (`user.name` and `user.email`) and repository status.

 Prerequisites

- Python 3.x** installed on your system
- Git installed and accessible via your terminal/PATH
